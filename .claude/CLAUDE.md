# Memorial Stickers

An archive of memorial stickers for fallen individuals, photographed in public
space. FastAPI + Postgres + MinIO behind a React frontend. See `README.md` for
the stack and `docker compose up --build` to run everything.

**Intent.** The project remembers these people in a good and positive way. It is
respectful and dignified, and deliberately not sad: the theme is daylight —
parchment, ink, olive, sun, tekhelet — and features celebrate a life rather than
perform a ritual of grief (a visitor adds a leaf to a person, not a candle).
`rules/frontend.md` has the full direction and the token map, and it is binding
for anything under `frontend/`.
